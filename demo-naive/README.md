# Синтетический шаблон отчёта — наивное демо

Данные вымышленные, компания «Меридиан» не существует.

Учебный шаблон: демонстрация «попросить модель сделать отчёт по шаблону» без правил и без
скилла. Тот же нейтральный шаблон, что в `../skill-skeleton/templates/` (байт-в-байт), — без
`SKILL.md` и без `scripts/`: модель работает вслепую, без инструкции, только с шаблоном на
экране.

## Промпт

```
claude -p "Сделай отчёт в docx по этому шаблону report-template.docx, данные возьми из головы, суммы в долларах, названия клиентов без юридической формы, компания Меридиан, август 2026." --setting-sources "project,local" --permission-mode auto --model claude-sonnet-5
```
