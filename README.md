# Домашка к ролику про Claude Code Skills — свой первый скилл

Данные вымышленные, компания «Меридиан» не существует.

Материалы к ролику про Claude Code Skills (плейлист «Claude Code глубоко»).

Задание: возьми документ, который делаешь регулярно, положи шаблон и инструкцию в папку и
получи готовый файл из одной строки запроса. «Запрос» — это обращение к Claude Code обычным
языком («собери отчёт за такой-то период из такого-то файла»), а не ручной вызов скрипта из
терминала: Claude сам находит скилл по `description` и запускает нужный скрипт — ручной вызов
годится только для проверки скрипта во время сборки скилла (раздел «Прогон» ниже), не как
результат домашки.

---

## Что внутри

- `gen/make_templates.py` — генератор синтетических шаблонов и их читаемых `.md`-близнецов
  (детерминирован, без случайности).
- `data/shipments.csv` — двенадцать вымышленных отгрузок компании «Меридиан» за август 2026:
  `date, client, product, qty, amount_usd`.
- `skill-skeleton/` — эталонный скилл: `SKILL.md`, `templates/report-template.docx`,
  `scripts/fill_report.py`.
- `demo-naive/` — тот же нейтральный шаблон без скилла и скрипта: демонстрация «попросить
  модель заполнить по шаблону» без правил.
- `demo-break/` — шаблон с колонтитулами, объединёнными ячейками и двухуровневой шапкой
  таблицы: на нём наивный скрипт делает не то.

## Установка

Скилл проекта живёт в `.claude/skills/<имя>/SKILL.md` — Claude Code подхватывает его
автоматически для сессий в этом репозитории (личный уровень — `~/.claude/skills/`, действует
на все проекты машины). Формат и расположения скиллов — официальная документация:
https://code.claude.com/docs/en/skills

Для своей домашки: создай папку, положи в неё `SKILL.md` по образцу `skill-skeleton/SKILL.md`
(шапка `name`/`description`, правила заполнения, команда запуска) и файлы, которые скрипту
нужны — свой шаблон и свой скрипт. Данные (свой CSV или другой источник) кладутся рядом со
скиллом, в `data/` в корне проекта — не внутрь папки самого скилла (`.claude/skills/<имя>/`):
скилл — это инструкция и инструмент, данные — то, что в него подставляют, и они меняются от
запуска к запуску.

## Прогон

Собрать оба синтетических шаблона заново (перезаписывает `skill-skeleton/templates/`,
`demo-naive/`, `demo-break/` тем же детерминированным содержимым):

```
python gen/make_templates.py
```

Заполнить нейтральный шаблон данными CSV:

```
python skill-skeleton/scripts/fill_report.py skill-skeleton/templates/report-template.docx data/shipments.csv report-август-2026.docx
```

Ожидаемый файл: шапка «Меридиан», период «август 2026», 12 строк таблицы в порядке CSV,
итог 164 850 $ — вычислен скриптом, в CSV не хранится.

## Своя домашка

> Собери свой первый скилл: возьми документ, который делаешь регулярно, положи шаблон и
> инструкцию в папку и получи готовый файл из одной строки запроса.

Разбери `skill-skeleton/` как образец структуры (`SKILL.md` → `templates/` → `scripts/`) и
собери свою версию по тому же принципу: шаблон документа, скрипт подстановки, `SKILL.md` с
понятным `description`, чтобы Claude Code сам находил скилл по задаче на обычном языке.
