# Отчёт об отгрузках — эталонный скилл

Данные вымышленные, компания «Меридиан» не существует.

## Что внутри

- `templates/report-template.docx` — шаблон: шапка компании, период, таблица с плейсхолдерами
  `{{DATE}}`, `{{CLIENT}}`, `{{PRODUCT}}`, `{{QTY}}`, `{{AMOUNT}}`, строка итога с
  `{{ROWS_COUNT}}` и `{{TOTAL}}` (`templates/report-template.md` — тот же текст глазами).
- `scripts/fill_report.py` — подставляет данные CSV в шаблон.

## Правила заполнения

1. Период всегда пишется словами: «месяц год» (пример: «август 2026»), не датами через слэш.
2. Одна строка таблицы шаблона клонируется по числу строк CSV; порядок сохраняется, лишние и
   пустые строки CSV не подставляются.
3. Суммы — в `$`, разряды разделены пробелом («14 400»), копейки/центы не показываются, если их
   нет в исходных данных.
4. Итог считает скрипт, суммируя `amount_usd` по всем строкам; в CSV итоговой строки нет и быть
   не должно — записанный заранее итог разойдётся с данными при следующем изменении CSV.
5. Шаблон должен быть простой таблицей без объединённых ячеек и без переменных полей компании в
   колонтитулах — скрипт их не читает (пример шаблона, на котором это ломается — `../demo-break/`).

## Команда запуска

```
python scripts/fill_report.py <шаблон.docx> <данные.csv> <выход.docx>
```

Пример на эталонных данных:

```
python scripts/fill_report.py templates/report-template.docx ../data/shipments.csv report-август-2026.docx
```
